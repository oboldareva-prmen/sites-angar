# Политика обработки персональных данных

**Статус документа:** заготовка для заполнения и юридической проверки.

Эта страница подготовлена как место для будущей политики обработки персональных данных сайта «АНГАР». До публикации необходимо добавить и проверить сведения об операторе, целях и правовых основаниях обработки, составе данных, сроках хранения, порядке отзыва согласия, мерах защиты и порядке обращений пользователей.

Не используйте этот документ как готовую к применению политику без заполнения обязательных сведений и юридической проверки.
