# Legacy Cloudflare configuration

Проект переведён на Netlify Functions и Neon PostgreSQL. Актуальная инструкция по публикации, базе данных, секретам и CRM находится в `docs/netlify-neon.md`.

Файлы старой Cloudflare Pages + D1 реализации сохранены в репозитории для истории и возможного ручного переноса данных. Они не используются маршрутизацией Netlify.
